## Method

Five tasks, each asking for a sibling of a file that already takes a
shortcut. No task named the shortcut or the correct form. Three environments:
the repository alone, the repository plus a conventions file, the repository
plus a `PreToolUse` lint gate. 25 trials per arm on
`claude-haiku-4-5-20251001`.

   Generic rules 15/20 to 3/20, p=0.0003; the clock rule 4/5 to 5/5, p=1.0.

## Known limitations at the time

One local-convention fixture. `jwt-issuer`'s prompt names `src/config/`, so
five of the seven exemplar-readers were partly directed. Five reps per cell
cannot separate 3/5 from 5/5 (p=0.44). No post-hoc linting arm, so the cost
claim had no fair comparison.
